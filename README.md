## 📌 Project: Student Marks Calculator

The `marks.py` program takes marks for five subjects and calculates the student's academic results.

### ✨ Features

- Takes marks for five subjects as input
- Stores marks in a Python list
- Calculates total marks and percentage
- Finds the highest and lowest marks
- Checks whether the student has failed any subject
- Assigns a grade based on the percentage
- Displays a result message

### 🛠️ Concepts Used

- Variables and data types
- `while` loops
- Lists and `append()`
- User input with `input()`
- Type conversion with `int()`
- Built-in functions: `sum()`, `max()`, and `min()`
- Conditional statements: `if`, `elif`, and `else`
- The `any()` function
- f-strings

### ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python marks.py
```

On some systems, you may need to use `python3 marks.py` instead.
